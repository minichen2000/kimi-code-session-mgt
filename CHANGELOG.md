# Changelog

## [0.1.0] - 2026-09-27

### Added

- Initial GUI for browsing Kimi Code sessions.
- Flat session list with sorting by title, updated time, wire size, or agent count.
- Display session title, created/updated time, and total wire log size.
- List every Agent's `wire.jsonl` log inside a session.
- "Reveal in file manager" support for Windows, macOS, and Linux.
- Delete session with confirmation.
- Adjustable font size.
- Single-file Windows executable built with PyInstaller.
