# Changelog

## [0.4.0] - 2026-09-30

### Added

- Session list now sorts by updated time descending on startup.

### Changed

- Releases are now built in the cloud: pushing a `v*` tag triggers GitHub Actions to build the single-file executable and publish the release automatically.

## [0.3.0] - 2026-09-29

### Added

- "查看" button for a selected Agent wire.jsonl log: opens it with the system default application (same as double-clicking the file).

## [0.2.0] - 2026-09-27

### Added

- Custom "KW" application icon for the executable file and the runtime window (`assets/icon.ico`, generated by `scripts/generate_icon.py`).

## [0.1.0] - 2026-09-27

### Added

- Initial GUI for browsing Kimi Code sessions.
- Flat session list with sorting by title, updated time, wire size, or agent count.
- Display session title, created/updated time, and total wire log size.
- List every Agent's `wire.jsonl` log inside a session.
- "Reveal in file manager" support for Windows, macOS, and Linux.
- Delete session with confirmation.
- Adjustable font size.
- Single-file Windows executable built with PyInstaller.
